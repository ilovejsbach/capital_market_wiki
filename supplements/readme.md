# kcm 보완층 (supplements)

「한국 자본시장의 이해」(2023)의 인쇄본 근거 위키(`../wiki/`)와 **분리된 층**이다. 인쇄본 위키는 책에 인쇄된 값만 쓰고(S4), 이 폴더는 책 이후의 변화·추가를 날짜별로 모아 정렬한다. 책 본문과 `wiki/` 문서는 이 층 때문에 수정하지 않는다.

- 수집 구간: 2021-01 \~ 2026-10 (집필 시점과 발행일 사이 공백 때문). 기준 시점: 2026년 10월 현재.
- 2021\~2023: 책 본문과 대조(`일치 / 책과 다름 / 책에 없음`). 2024-01 이후: 변화 반영과 신규 등재.
- 작성(조사)과 판정(독립 재확인)은 다른 에이전트가 했다. 판정이 `verified`·`corrected`인 기록만 올렸다(`corrected`는 판정자의 수정값 반영). `unverified`와 오케스트레이터가 보류한 기록은 held.md, 확인 못 한 것은 candidates.md에 올렸다. 계획 단계 서술이 이후 시행령으로 확정돼 달라진 경우는 책 오류가 아니라 `변화 유형: 계획→확정`으로 기록한다. 책 오류로 확인된 값은 위키 원문 층에서 정정하고(수시 린트) 이 층에는 이력을 남긴다.
- 1차 자료만 근거로 삼았고, 언론·검색 요약에 의존한 기록은 note와 신뢰도(낮음)에 표시했다. 계산·추정으로 만든 값은 없다.

| 파일 | 내용 |
|---|---|
| `timeline.md` | 발생일 순 전체 기록 |
| `by-chapter.md` | 책 장별 묶음 |
| `by-page.md` | 책 pdf 쪽 색인 |
| `author-check.md` | 작가 결정 반영 상태, 남은 확인 사항, 신뢰도 낮음 목록 |
| `corrections.md` / `corrections.jsonl` | 책 안 불일치를 권위 있는 출처로 검증한 정정 이력(위키 원문 층에 반영한 것과 안 한 것) |
| `candidates.md` / `candidates.jsonl` | 확인 못 한 것의 향후 보완 후보(이유·시도한 출처·다음에 볼 출처·우선순위) |
| `held.md` / `held.jsonl` | 검증 보류 기록(중복 기록은 별도 절) |
| `duplicates.jsonl` | 기존 기록과 같아 올리지 않은 중복 기록 |
| `coverage.json` | 능동 탐색·조사 범위(키워드, 목록 순회, 지시문으로 걸러진 판정) |
| `part2/` | 책이 다루지 않은 주제의 「2부」 후보: `themes.md`(주제별 카드, S7 19개+기록에서 파생한 19개, 연결된 기록), `unassigned.md`, `README.md` |
| `config.json` | 책별 설정(정책 보류, 표기, 후보 수동 목록, 변화 유형 덮어쓰기, 요약 제거 등). 조립은 `loop.py supplements --book kcm` |
| `records.jsonl` | 구조화 정본(기록 한 줄) |
| `stats.json` | 건수 요약 |

상태는 모두 `draft`이며 `reviewed`는 사람만 단다. 이 층은 `loop.py lint`·`merge` 대상이 아니다(`wiki/` 밖).
